# **Aplicación PDDH para INVENTARIO**

*NOTA: Este programa es únicamente para uso local. No se recomienda compartirlo con nadie más a parte de la institución la cual hace uso de esta misma herramienta.*

*A continuación se compartirá el siguiente enlace hacia el archivo de documentación de errores parcheados y cambios hechos, así cómo con sus fechas. El enlace siempre será de este mismo repositorio. Así como adjunto después de ese documento irá las descripciones generales del proyecto / herramienta.*
##
*NOTAS DE PARCHES:* [CAMBIOS Y PARCHES](NOTAS_PARCHES.md)
##

### PROPÓSITO:
El programa tiene cómo único propósito el de:

> - Almacenar
> - Actualizar
> - Leer
> - Borrar
> - Exportar a diferentes formatos (Word, Excel, y PDF)

Todos los datos serán únicamente de inventario. Nada más.

##
### ¿Qué datos almacena?
Unicamente puede almacenar datos del siguiente tipo:

> - Código del objeto
> - Descripción del objeto
> - Marca del objeto
> - Módelo del objeto
> - Serie del Objeto
> - Fecha de adquisición del objeto
> - Valor unitario del objeto

##

### Importante
Mi persona no incluyó ningún archivo malicioso ni tampoco código de telemetría que envíe datos a un servidor o lugar. El programa es de ambiente estrictamente local. En otras palabras, la información que se ingrese, vivirá únicamente en la computadora en la cual la herramienta se ejecuta.
